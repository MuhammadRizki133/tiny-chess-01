A deterministic chess engine in under 4 KB of Python: 0x88 board, negamax alpha-beta with PVS, transposition table, quiescence, null-move pruning and LMR, driven by a fixed 150,000-node budget so replays match move for move. It speaks the make.fun trial protocol over HTTP and plays the house gauntlet.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
